# Support

AcmeMux is community-supported MVP software and has no guaranteed free support
response time.

- Use [Discussions](https://github.com/acmemux/AcmeMux/discussions) for setup
  questions, workflows, and roadmap ideas.
- Use the [application issue tracker](https://github.com/acmemux/AcmeMux/issues)
  for reproducible defects.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.
- Use [contact@certleap.net](mailto:contact@certleap.net?subject=AcmeMux%20inquiry)
  for a general project inquiry that does not fit an issue or discussion.
- Use the [sponsorship page](https://acmemux.com/sponsor/) or
  [sponsorship@certleap.net](mailto:sponsorship@certleap.net?subject=AcmeMux%20sponsorship)
  for funding inquiries. Sponsorship is not a support contract and does not
  provide implementation priority or guaranteed delivery.

Before asking for help, remove secrets and collect the AcmeMux version, exact
lego identity, operating system, workspace state, reported reason code, and the
smallest redacted transcript that demonstrates the problem.
