# Contributing to AcmeMux

Thank you for helping improve AcmeMux. The project is at MVP stage. Source is
public while the first tagged release and signed release artifacts are being
qualified.

## Useful contributions now

- Describe a real certificate-management workflow in an Ideas discussion.
- Vote on one existing roadmap proposal with a positive reaction.
- Improve public documentation or report a broken guide.
- Provide reproducible qualification evidence for a distribution or platform.
- Report a bug with redacted logs and exact runtime information.
- Sponsor an accepted roadmap item.

Do not post passwords, session cookies, DNS credentials, ACME account keys,
certificate private keys, tenant identifiers, or unredacted configuration.

## Proposing a feature

Search [Ideas](https://github.com/acmemux/AcmeMux/discussions/categories/ideas)
and the [product roadmap](https://acmemux.com/roadmap/) first. A strong proposal
explains the operator problem, who experiences it, the current workaround, the
security boundary it touches, and how success can be verified. Provider
requests should link to the upstream lego provider documentation and name the
required credential modes.

## Code contributions

Open an issue or discussion before a large implementation. Keep pull requests
bounded, add tests, preserve native
lego workspace ownership, and do not broaden support claims without matching
qualification and documentation. Passing on a new platform is evidence, not an
automatic support commitment.

All contributions are reviewed for security, maintainability, licensing,
accessibility, and compatibility. Maintainers may decline work that conflicts
with the project's trust boundary even when it is popular or funded.
